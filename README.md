# flutter-property-search

A bilingual (Arabic/English) property search app built with Flutter, with full right-to-left support.

> 🗓️ Planned, starting January 2027

## Planned features

- Arabic and English with full RTL layout
- Map search with grouped pins and filters
- AED and SAR price formatting
- Saved searches that work offline
- Accessibility: screen reader and large text support
